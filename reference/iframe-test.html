SONAIR — Iframe Compatibility Test

Use this file to verify your sub-portal loads correctly inside an iframe before the demo.

Instructions:
1. Replace the src attribute on the <iframe> below with your deployed sub-portal URL.
2. Open this file in a browser (double-click, or serve locally with python -m http.server).
3. Open DevTools (F12) → Console tab.
4. Check: no X-Frame-Options or Content-Security-Policy frame-ancestors errors.
5. Check: the portal renders visibly — not a blank white box.
Pre-demo checklist (Connector owns these):
  • No X-Frame-Options error in DevTools Console
  • No Content-Security-Policy frame-ancestors error in DevTools Console
  • Portal renders and is not a blank white box
  • Portal reads theme.config.json and applies primary_color
  • federation.json is present at repo root and passes python validate_submission.py
